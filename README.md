# Yifun Life 智能报价中心

面向亦玩产品选型、套餐配置和报价输出的内部系统。

线上入口：[打开报价系统](https://yifun-life-quote.enquiry150941.chatgpt.site)

## 当前实现范围

系统现已收录 1,755 个 SKU，并以《2026 产品册》的八大类作为一级目录：

1. 职业体验 / Career Experience
2. 生活场景 / Lifestyle Scene
3. 农牧生活 / Agro-pastoral Life
4. 动物世界 / Animal World
5. 车生活 / Car Life
6. 拼装手工 / Assemble by Hand
7. 机械传动 / Playground Scenes
8. 多媒体互动 / Multimedia Interactivity

原有的产品大类、区域分类和三级分类均继续保留。当前已经完成套餐功能的仅为**厨房专区**；其他区域仍按单个 SKU 选购，不受影响。

## 使用流程

### 1. 登录

打开系统后需先登录。为保护报价数据，登录状态会在 30 分钟后自动退出。

### 2. 浏览与单点选品

- 左侧按八大类展开，可继续按区域查看产品。
- 顶部支持名称、SKU 和分类搜索。
- 可切换人民币 / CNY 与美元 / USD 显示，切换不会删除或改写产品价格。
- 产品卡片上的“添加”会把独立 SKU 直接加入报价清单。
- 可使用颜色、带屏幕 / 投影、常用推荐等筛选条件。

### 3. 维护 SKU

点击任意产品卡片，会从右侧打开 SKU 编辑抽屉。当前可维护：

- 主图、产品名称、人民币参考价、体积和库存；
- 一级大目录、产品大类、区域分类和三级分类；
- 主色标签；主图上传后会自动给出主色建议；
- “带屏幕”标记与常用推荐标记；
- 常用搭配 SKU。

SKU 的名称、价格、图片和库存是产品的唯一来源。套餐只引用 SKU，不复制这些资料。

## 数据与图片存储

- 1,755 个 SKU 的资料保存在 Cloudflare D1 数据库；
- 产品主图保存在 Cloudflare R2 对象存储，数据库只保留图片 key，并通过链接读取；
- 网站包和 GitHub 源代码不再包含产品图片文件。未来接入自有 Cloudflare 域名时，只需替换图片链接域名，无需重新导入 SKU。

## 厨房专区套餐

进入「生活场景 → 厨房专区」，可以在以下三种子分类间切换：

- **套餐 / Packages**：按配置规则选购一个厨房方案；
- **主产品 / Main products**：单独选购厨房模拟设备；
- **附件玩具 / Add-on toys**：单独选购厨房玩具。

当前厨房专区包含 152 个 SKU：44 个主产品和 108 个附件玩具。默认提供“厨房区 · 自由配置套餐”：主产品组自动关联厨房模拟设备，附件玩具组自动关联厨房玩具。

### 配置套餐

在“管理厨房套餐”中，可为每个套餐添加或调整多个选项组：

- 选项组来源：自动关联厨房主产品、自动关联厨房附件玩具，或手动指定 SKU；
- 选择方式：单选、多选、可复选（同一 SKU 可增加数量）；
- 每组选项的最少 / 最多选择数量；
- 每个 SKU 的最少 / 最多购买数量；
- 套餐名称和说明。

选择完成后，点击“加入套餐至报价单”。系统会把所选的真实 SKU 加入报价清单，并按独立 SKU 的实时名称、价格与库存计算；套餐本身不会生成一份重复的产品数据。

## 报价单

点击右上角“报价清单”可以调整数量，并一键生成中英文报价单。

报价单支持：

- 项目名称、设计师名称、业务员名称、币种、日期和项目数量；
- 产品按照体验区域分组，同一区域的模拟设备和玩具汇总显示；
- SKU、主图、品牌、规格、单位、数量、单价、金额、色卡、体积、备注；
- 包装费、除甲醛、运输费、安装费、税额和设计费抵扣；
- 安装费可注明是否含工人出行食宿；美元报价自动不显示税额；
- 可填写公司地址；导出 PDF 时每页显示页码和公司地址，产品图片保留且避免在行内断开。

## 分类管理

顶部“分类管理”可维护产品大类之下的区域分类及三级分类。八大类一级目录以《2026 产品册》为标准，在当前版本中固定不随意新增。

## 数据与保存规则

- 产品编辑、分类、推荐关系、库存和厨房套餐配置都会保存到系统数据库；
- 产品图片保存为产品资源；
- 厨房套餐保存的是 SKU 引用和选择规则，因此后续修改 SKU 的名称、价格、图片或库存后，套餐会自动同步；
- 已加入报价单的商品仍以独立 SKU 的数量与价格参与计算。

## 维护提醒

- 请先在 SKU 编辑抽屉补齐库存，套餐内才会显示可用库存数字；未填写时显示“待维护”。
- 增加新的厨房 SKU 后，如其区域分类包含“厨房”，会自动进入厨房套餐的“自动关联”选项组。
- 为其他区域增加套餐时，建议沿用“引用 SKU + 保存选择规则”的方式，避免建立重复产品资料。

## 本地维护命令

```bash
pnpm dev
pnpm build

```
