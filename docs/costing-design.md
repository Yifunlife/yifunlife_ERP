# 核算管理界面

沿用系统白底、深蓝、原品牌标志与表格样式。

- 四个入口：材料库、人工工序库、款号组合核算、核算记录。
- 材料和工序像 SKU 一样维护独立编码，表格显示单价与引用款号。
- 款号入口先展示列表，添加或选择款号后进入组合编辑。
- 组合编辑保留方案一布局：左侧材料和人工分区，款号信息区填写统一难度系数，右侧显示基础材料与人工成本、统一系数、最终成本与售价。
- 下拉选择库项目后，只设置用量和工时；名称、规格、单位、单价来自库。
- 公共库与组合共用页面底部保存操作及修改原因，切换入口保留草稿。
- 初始价格为空，待核算与零金额明确区分。窄屏表格可横向滚动、汇总移到明细下方。
- 原清单导入入口、成本权限与历史快照保持不变。

- 库编号只读并自动顺序生成；材料库、人工库和组合选择均提供编号/名称搜索。
