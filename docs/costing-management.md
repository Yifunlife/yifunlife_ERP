# 核算管理：材料库、人工工序库与款号组合

## 使用顺序

1. 在材料库维护编码、名称、规格、单位和成本单价。
2. 在人工工序库维护编码、工序名称、说明和每人时工资。
3. 在款号组合核算中添加或选择款号，再按部位从两个库选择项目，填写每平方米用量、人时，在款号上设置一个统一难度系数，以及款号售价单价。
4. 填写修改原因，保存全部修改。清单仍从原报价系统入口导入，按款号组合计算。

## 数据关系与计算

- 库项目有稳定内部标识和可编辑业务编码。组合只保存引用、部位、用量和启用状态；单价取公共库。
- 同一库项目可被多个款号引用。改价影响后续新核算；改某个款号用量不影响其他款号。
- 材料成本＝面积 × 每平方米标准用量 × 库单价。
- 人工成本＝面积 × 每平方米标准人时 × 每人时工资。
- 总成本＝（基础材料成本＋基础人工成本）× 款号统一难度系数；售价＝面积 × 本款号对应部位的售价单价。
- 房子、矮墙维持现有面积规则，房子夹层、屋顶、玻璃分别计算；扶手独立报价。当前未增加大型家具的独立尺寸算法。
- 单价和用量允许留空，缺项显示待核算；不得用零代替未知。已引用的库项目禁止在界面删除或修改单位，可建立新规格编码。

## 兼容与权限

- 现有类别规则在编辑页面转换成库和独立款号组合；名称、规格、单位、单价不同的项目不合并。转换后的结果随保存生效。
- 使用现有规则版本表持久保存两库与组合，无需新增数据库迁移。旧版规则仍可读取，旧快照不改写。
- 保存全套设置形成新版本，沿用并发版本检查；核算记录保存当时的库价格和组合。
- 只有老板及核算人员可访问库、组合与成本。核算人员也能报价；普通报价接口仅返回售价。
- 人民币售价独立维护；未配置美元售价时阻止对应美元报价保存。

## 验证

覆盖旧规则转换前后成本售价一致、公共改价、款号用量隔离、无效引用和重复编码校验、接口持久保存、原清单导入和历史快照不变。

- 材料及工序编码分别按 CL、RG 顺序自动生成。服务端在版本并发检查下分配编码，并保留已用最大序号；已删除编号不重复使用。
- 两库和款号组合选择框支持按编号、名称、规格筛选。常规款号难度系数为 1；原明细系数不一致时，转换后统一系数留空待确认，不猜测。售价不再乘难度系数。

## 共用美元汇率（2026-10-20）

- 标准件美元售价＝产品库出厂价 ÷ 共用美元汇率，四舍五入至小数点后两位；国内VIP价及其覆盖值不参与美元换算，零元出厂价保留为零。
- 汇率口径为“1美元＝多少人民币”，在“款号与系数 → 共用美元汇率”维护，点击“保存修改”生效。
- 产品库显示和新清单导入共用该汇率；非标房子继续按核算所得人民币售价除以同一汇率。标准件按出厂价进行美元换算。
- 报价导出沿用该报价内的美元单价；历史报价及已生成核算快照不追溯改价。重新打开报价页面或重新导入清单，才读取最新价格和汇率。
- 材料、人工、成本倍率不改变标准件人民币售价。缺少出厂价时，美元价为空，不退回原导入的固定美元价。
