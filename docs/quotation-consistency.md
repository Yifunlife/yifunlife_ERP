# 报价单统一规则

适用于所有导入报价、普通选品报价、历史报价恢复与后续 Excel 导出，不按项目名称、SKU 或示例文件启用。

- 网页与 Excel 使用同一份当前报价数据。标准报价统一18列表头及顺序；导入原表保留其表头、图片、区域、行序、说明、合并单元格和布局。
- 仅为缺失英文的中文内容补充英文；已有中英文直接复用。翻译报价副本，不修改产品库或历史原始记录，不翻译款号、公式和数值。
- 删除红色、新增绿色、修改蓝色、客户自理黄色。删除和客户自理行继续展示与导出，保留数量、原始资料及修改记录，但金额归零。
- 明细、区域小计、合计、成本及最终数据提取统一排除删除、客户自理和零数量项目；新增和修改项目按当前有效数量与价格计算一次。
- 同一行标识重复出现时，以最新状态为准；相同 SKU 在不同区域或不同独立行中出现时，仍是不同项目，不能按 SKU 合并。
- 修改记录用于追溯，不作为产品明细再次统计。重导入恢复原修改记录，不因翻译或格式处理追加业务修改。
- 有最终确认版本的项目，最终数据从该版本提取有效项目，不累加历次版本；历史原表和记录仍保留。

回归验证涵盖人民币、美元、出厂价，普通报价导出后再次导入，双语重复处理，四色状态、同款独立行及重复行标识。
